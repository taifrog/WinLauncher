# 自分専用 Windows ランチャー

タスクバー（システムトレイ）に常駐し、登録したコマンド（PowerShell / cmd）をワンクリックで実行できるランチャーです。

## できること

- トレイアイコンをクリック → 登録済みコマンドの一覧がメニューで表示され、選ぶと実行
- 「＋ 新規登録」→ 専用ダイアログで以下を設定して登録
  - メニュー名
  - 実行コマンド（複数行OK）
  - 実行シェル（PowerShell / cmd）
  - 引数（最大3件、任意）：各欄に説明文を入力して「コマンドに挿入」を押すと、コマンド欄のカーソル位置に `{ARG1}` `{ARG2}` `{ARG3}` が挿入されます
- コマンドに `{ARG1}` などが含まれている場合、実行時にその場で値の入力ダイアログが出て、入力した値に置き換えてから実行されます
- 「編集・削除」から登録済みコマンドの修正・削除が可能
- 実行結果はコンソールウィンドウが新規に開いて表示され、終了後もウィンドウが残るので結果を確認できます

## セットアップ

1. Python 3.9 以降を Windows にインストール
2. 必要ライブラリをインストール

   ```
   pip install pystray pillow
   ```

3. `launcher.py` を好きなフォルダに置いて実行

   ```
   pythonw launcher.py
   ```

   `pythonw` を使うとコンソール窓を出さずに常駐できます（`python launcher.py` だとコンソールが1つ残ります）。

   実行すると `commands.json` が同じフォルダに自動生成され、登録内容が保存されます。

## 引数機能の使い方（例）

例えば「指定フォルダを Explorer で開く」コマンドを、フォルダパスだけ毎回変えて使いたい場合：

1. 実行コマンド欄に `explorer.exe "{ARG1}"` と入力（直接手入力でも、引数1の説明を書いて「コマンドに挿入」ボタンで挿入してもOK）
2. 引数1の説明欄に「開くフォルダのパス」と入力
3. シェルは cmd でも PowerShell でもどちらでも可
4. 保存して、トレイメニューからこのコマンドを実行すると、「開くフォルダのパス」を尋ねる小さいダイアログが出るので、パスを入力して「実行」

引数に日本語パスやスペースを含む値を入れる場合は、上記のようにコマンド側で `"{ARG1}"` のように引用符で囲んでおくと安全です。

## Windows起動時に自動で常駐させたい場合

1. `Win + R` → `shell:startup` と入力して Enter（スタートアップフォルダが開く）
2. `launcher.py` へのショートカットを作成し、リンク先を以下のようにする

   ```
   pythonw.exe "C:\path\to\launcher.py"
   ```

   （`pythonw.exe` のフルパスが分からない場合は `where pythonw` で確認できます）

3. そのショートカットをスタートアップフォルダに置く

## 単体の .exe にしたい場合（配布・二重実行防止など）

PyInstaller を使うと 1 つの exe にまとめられます。

```
pip install pyinstaller
pyinstaller --onefile --noconsole --name PersonalLauncher launcher.py
```

`dist\PersonalLauncher.exe` が生成されます。この exe をスタートアップフォルダのショートカットにすると、Python 環境がなくても常駐起動できます。
（`commands.json` は exe と同じフォルダに作られます）

## ファイル構成

- `launcher.py` … 本体スクリプト
- `commands.json` … 登録コマンドの保存先（初回実行時に自動生成）

## 補足・設計メモ

- コマンドは実行時に一時的な `.ps1`（PowerShell）または `.bat`（cmd）ファイルとして書き出し、新しいコンソールウィンドウで実行しています。複数行のスクリプトや `if` 分岐なども問題なく書けます。
- 引数プレースホルダーは `{ARG1}` `{ARG2}` `{ARG3}` の3つ固定です。未使用の引数欄は空のままで問題ありません。
- 「引数の説明を入力→挿入ボタンでコマンド内に配置」という設計にしているため、値そのものは登録時ではなく実行のたびに入力する形になっています。もし逆に「登録時に固定値を埋め込みたい」場合は、コマンド欄に直接その値を書いてしまえば同様に動作します。
